# 网页金句收藏Chrome扩展

## 项目概述

网页金句收藏是一款Chrome浏览器扩展，旨在帮助用户快速收藏、整理和分享网页中的精彩句子。用户可以通过简单的操作，将浏览网页时遇到的金句保存下来，添加标签和笔记，并在需要时方便地查看和分享。

当前版本：v3.0

## 功能需求

### 核心功能

1. **金句收藏**
   - 支持选中网页文本后右键收藏
   - 支持快捷键收藏选中内容
   - 自动记录金句来源网页的URL和标题

2. **金句管理**
   - 按时间、来源网站、标签等多种方式分类查看
   - 支持为金句添加个人笔记
   - 支持为金句添加自定义标签
   - 支持编辑和删除已收藏的金句

3. **金句搜索与智能处理**
   - 支持按关键词搜索已收藏的金句
   - 支持按标签筛选金句
   - 集成DeepSeek R1 AI模型，提供智能文本总结功能

4. **数据导出导入**
   - 支持将收藏的金句导出为JSON或CSV格式
   - 支持从文件导入金句数据

5. **金句分享**
   - 支持将金句分享到社交媒体
   - 支持生成金句图片

### 扩展功能

1. **云同步**
   - 支持将数据同步到云端，实现多设备访问
   - 支持账号登录和数据备份

2. **智能推荐**
   - 基于用户收藏习惯，推荐相似的金句
   - 显示热门收藏的金句

## 技术规范

### 开发要求

- 使用Chrome扩展的Manifest V3规范开发
- 使用Service Workers替代Background Pages
- 遵循最小权限原则设计Content Scripts
- 实现响应式设计，确保在不同分辨率下的良好体验
- 所有用户数据传输使用HTTPS协议

### 技术栈

- **前端**：HTML5, CSS3, JavaScript (ES6+)
- **UI框架**：可选使用轻量级框架如Bootstrap或Tailwind CSS
- **存储**：使用Chrome Storage API存储本地数据
- **云同步**：可选使用Firebase或自建后端服务

### 文件结构


## 用户界面设计

### 弹出窗口

- 简洁明了的界面，显示最近收藏的金句
- 提供快速添加、搜索和管理功能的入口
- 支持暗黑模式和自定义主题

### 管理页面

- 提供完整的金句管理功能
- 支持列表视图和卡片视图切换
- 提供丰富的筛选和排序选项

### 右键菜单

- 在选中文本时提供"收藏金句"选项
- 提供快速添加标签的子菜单

## 安装与使用

### 安装方法

1. 从Chrome Web Store下载安装（发布后提供链接）
2. 开发模式下安装：
   - 下载本项目代码
   - 打开Chrome浏览器，进入扩展管理页面 (chrome://extensions/)
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"，选择项目文件夹

### 使用指南

1. **收藏金句**：
   - 在网页中选中文本，右键点击"收藏金句"或使用快捷键
   - 在弹出的窗口中可添加标签和笔记

2. **查看金句**：
   - 点击浏览器工具栏中的扩展图标
   - 在弹出窗口中可查看最近收藏的金句
   - 点击"管理所有金句"进入完整管理页面

3. **管理金句**：
   - 在管理页面可编辑、删除、搜索和筛选金句
   - 可为金句添加或修改标签和笔记

4. **导出导入**：
   - 在管理页面的设置选项中可导出和导入数据
